Politique de confidentialité

Ce que TranscriPilote et ce site font de vos données, et ce qu'ils n'en font pas.

Dernière mise à jour : 15 novembre 2026

En bref

TranscriPilote traite vos réunions sur votre ordinateur. Ni l'éditeur ni personne d'autre n'a accès à vos enregistrements, à vos transcriptions ou à vos résumés. L'application ne contient aucune mesure d'audience, aucun traceur et aucune publicité.

L'application

Vos enregistrements, transcriptions, résumés et réglages sont conservés dans le dossier %LOCALAPPDATA%\TranscriPilote de votre compte Windows. Ils ne sont envoyés nulle part.

L'application se connecte à Internet uniquement dans les cas suivants :

  • vérifier et télécharger les nouvelles versions, sur GitHub (désactivable dans les réglages) ;
  • télécharger les modèles de transcription, une fois, au premier usage, depuis Hugging Face ;
  • télécharger l'outil de conversion vidéo FFmpeg, une fois, si vous importez une vidéo ;
  • copier vos données vers votre propre Google Drive ou OneDrive, si vous activez la sauvegarde : elles vont directement de votre PC à votre compte ;
  • utiliser l'identification des intervenants (bêta), qui télécharge un modèle avec la clé Hugging Face que vous fournissez.

Les résumés et les questions sont traités par Ollama, qui fonctionne sur votre PC.

Ce site

Le site est hébergé par GitHub Pages, et les installateurs par GitHub. Comme tout hébergeur, GitHub reçoit l'adresse IP des visiteurs pour délivrer les pages ; voir la déclaration de confidentialité de GitHub.

Pour afficher la dernière version et le nombre de téléchargements, votre navigateur interroge l'API publique de GitHub. Le site n'utilise aucun cookie ni outil de mesure d'audience.

Après un clic sur « Télécharger », deux questions facultatives vous sont proposées : votre pays et la façon dont vous avez connu TranscriPilote. Si vous y répondez, seules ces réponses et le numéro de version sont enregistrés, chez le prestataire Supabase, sans nom ni adresse e-mail. Elles servent uniquement à savoir où le logiciel est utilisé. Votre navigateur retient localement que la question vous a déjà été posée.

Vos droits

Pour toute question sur vos données, ou pour exercer vos droits d'accès et d'effacement, écrivez via la page Contact. Vous pouvez aussi saisir la CNIL.
