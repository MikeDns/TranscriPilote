Installation

Prêt en quelques minutes

Téléchargez

Récupérez l'installateur avec le bouton ci-dessus.

Installez

Lancez-le : il prépare tout seul les composants nécessaires. Comptez quelques minutes la première fois.

Utilisez

Ouvrez TranscriPilote depuis le menu Démarrer ou le bureau. Une visite guidée d'une minute, facultative, vous présente chaque fonction.

Configuration requise

Windows 10 ou 11 (64 bits), 16 Go de RAM recommandés (8 Go minimum), environ 10 Go d'espace disque. Aucune carte graphique nécessaire.

Résumés et discussion

Installez aussi Ollama, gratuit, qui fait tourner l'IA sur votre PC. TranscriPilote le démarre et le configure tout seul.

Mises à jour intégrées

Les nouvelles versions se préparent en arrière-plan et s'installent d'un clic, sans réinstaller. Vos données sont conservées.

Windows affiche « Windows a protégé votre ordinateur »

C'est habituel pour les logiciels récents. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ». Chaque version est publiée avec ses sommes de contrôle SHA-256 (fichier SHA256SUMS.txt), qui permettent de vérifier que le fichier n'a pas été modifié.

Où sont stockées mes données ? Comment désinstaller ?

Vos réunions et réglages sont dans %LOCALAPPDATA%\TranscriPilote. Pour désinstaller : Paramètres Windows → Applications → TranscriPilote. Vos données sont conservées ; supprimez ce dossier pour tout effacer.
