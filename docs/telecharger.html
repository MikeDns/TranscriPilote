Télécharger TranscriPilote

Gratuit, pour Windows 10 et 11. L'installation se fait dans votre profil, sans droits administrateur.

Télécharger pour WindowsToutes les versions

Windows 10 et 11, gratuit

Installation

  1. Téléchargez l'installateur

    Avec le bouton ci-dessus. Il pèse une quinzaine de mégaoctets.

  2. Lancez-le

    Il prépare tout seul les composants nécessaires. Comptez quelques minutes la première fois.

  3. Ouvrez TranscriPilote

    Depuis le menu Démarrer ou le bureau. Une visite guidée d'une minute, facultative, présente chaque fonction.

Configuration requise

SystèmeWindows 10 ou 11, 64 bits
Mémoire16 Go recommandés, 8 Go minimum
Espace disqueEnviron 10 Go (application et modèles)
Carte graphiqueAucune n'est nécessaire
Droits administrateurNon nécessaires : installation dans votre profil
Résumés et questionsOllama, gratuit, installé une fois

Bon à savoir

Windows affiche « Windows a protégé votre ordinateur »

L'installateur n'est pas encore signé numériquement, ce qui déclenche cet avertissement pour les logiciels récents. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Chaque version est publiée avec ses sommes de contrôle SHA-256 (fichier SHA256SUMS.txt), qui permettent de vérifier que le fichier n'a pas été modifié.

Faut-il installer autre chose ?

Pour les résumés et les questions, installez aussi Ollama, gratuit, qui fait tourner l'IA sur votre PC. TranscriPilote le démarre et le configure tout seul. La transcription, elle, fonctionne sans.

Comment se font les mises à jour ?

Les nouvelles versions se préparent en arrière-plan et s'installent quand vous le décidez, sans réinstaller et sans perte de données. Jamais pendant un enregistrement ou une transcription.

Où sont mes données ? Comment désinstaller ?

Vos réunions et réglages sont dans %LOCALAPPDATA%\TranscriPilote. Pour désinstaller : Paramètres Windows, Applications, TranscriPilote. Vos données sont conservées ; supprimez ce dossier pour tout effacer.
