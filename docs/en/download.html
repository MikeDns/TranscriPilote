Installation

  1. Download the installer

    With the button above. It is about fifteen megabytes.

  2. Run it

    It prepares the required components by itself. Allow a few minutes the first time.

  3. Open TranscriPilote

    From the Start menu or the desktop. An optional one-minute tour presents each feature.

System requirements

Memory16 GB recommended, 8 GB minimum

Good to know

Windows shows “Windows protected your PC”

The installer is not digitally signed yet, which triggers this warning for recent software. Click “More info”, then “Run anyway”. Each release is published with its SHA-256 checksums (SHA256SUMS.txt file), so you can check that the file has not been modified.

Do I need to install anything else?

For summaries and questions, also install Ollama, free, which runs the AI on your PC. TranscriPilote starts and configures it by itself. Transcription works without it.

How do updates work?

New versions are prepared in the background and installed when you decide, without reinstalling and without losing data. Never during a recording or a transcription.

Where is my data? How do I uninstall?

Your meetings and settings are in %LOCALAPPDATA%\TranscriPilote. To uninstall: Windows Settings, Apps, TranscriPilote. Your data is kept; delete that folder to erase everything.
